# Changelog

## 1.0.1 — development channel

- Added labels for Back to simple creation, Styles, Audio, style suggestions and Instrumental controls.
- Improved play-count and like-count announcements.
- Added dedicated labels for every language and regional directory included with the add-on.
- Declared compatibility through the experimental NVDA 2027.1 API for the development channel.
- Changed the version to the numeric format required by the NVDA Add-on Store.

## 1.0.0 — stable channel

- First stable Store-ready release.
- Labels recognised controls on the Suno AI website.
- Announces song-generation progress and completion.
- Provides manual and automatic diagnostic reports.
- Adds a Suno AI submenu and an NVDA Settings category.
- Includes manuals and localisation resources.
- Declared compatibility through NVDA 2026.2.
