Manual — Acessibilidade para o Suno AI

Version 1.0.1 dev — Daniel SonarCode — DEV

Este complemento melhora a acessibilidade do site Suno AI com o NVDA.

O complemento anuncia quando a criação começa e quando a música fica pronta para baixar.

Controles identificados

Comentários, Curtir, Não curtir, Compartilhar, página inicial, menu, cobrança e campo de criação.

Diagnóstico

No NVDA, abra Ferramentas, Suno AI e selecione Criar diagnóstico detalhado. As opções ficam em Preferências, Configurações, Suno AI.

Compatibilidade

NVDA 2014.1 a 2027.1; Chrome, Microsoft Edge, Firefox, Brave e Vivaldi.
