Manual — Accesibilidad para Suno AI

Version 1.0.1 dev — Daniel SonarCode — DEV

Este complemento mejora la accesibilidad del sitio Suno AI con NVDA.

El complemento anuncia cuándo comienza la creación y cuándo la canción está lista para descargar.

Controles identificados

Comentarios, Me gusta, No me gusta, Compartir, inicio, menú, facturación y campo de creación.

Diagnóstico

En NVDA, abre Herramientas, Suno AI y elige Crear diagnóstico detallado. Las opciones están en Preferencias, Opciones, Suno AI.

Compatibilidad

NVDA 2014.1 a 2027.1; Chrome, Microsoft Edge, Firefox, Brave y Vivaldi.
